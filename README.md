# โต๊ะเรียงไพ่ทาโรต์

เว็บสำหรับเรียงไพ่ทาโรต์ให้ตรงกับที่เปิดจริง แล้วบันทึกเป็นรูป PNG ไปใส่ในเอกสาร มีคู่มือการอ่านไพ่และความหมายไพ่ 78 ใบในหน้าเว็บ

## ไฟล์ในโฟลเดอร์นี้

```
index.html     หน้าเว็บ (ต้องชื่อนี้)
style.css      หน้าตา
app.js         การทำงาน
meanings.js    ความหมายไพ่และเนื้อหาคู่มือ (แก้ข้อความได้)
cards/         โฟลเดอร์รูปไพ่ (สร้างเอง ใส่รูปเข้าไป)
README.md      ไฟล์นี้
```

## เอาขึ้นเว็บด้วย GitHub Pages

1. สมัครหรือล็อกอิน github.com แล้วสร้าง repository ใหม่ (New repository) เลือก Public
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป รวมโฟลเดอร์ `cards` ถ้ามี แล้วกด Commit changes
3. ไปที่ Settings แล้วเลือก Pages ตรง Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอ 1 ถึง 2 นาที เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`

## ใส่รูปไพ่ให้ขึ้นเองบนเว็บ

สร้างโฟลเดอร์ชื่อ `cards` ใน repository แล้วอัปโหลดรูปไพ่เข้าไป เว็บจะโหลดรูปมาแสดงให้เองเมื่อไพ่ใบนั้นถูกวางบนโต๊ะ

มี 2 วิธีตั้งชื่อไฟล์ เลือกวิธีใดวิธีหนึ่งหรือผสมกันก็ได้

**วิธีที่ 1 ตั้งชื่อไฟล์ตามมาตรฐาน** นามสกุล `.jpg` `.png` หรือ `.webp`

| ไพ่ | ชื่อไฟล์ |
|---|---|
| เมเจอร์ 0 ถึง 21 | `m0` ถึง `m21` (เช่น `m0.jpg` = The Fool, `m16.jpg` = The Tower) |
| ไม้เท้า เอซ ถึง ราชา | `w1` ถึง `w14` |
| ถ้วย เอซ ถึง ราชา | `c1` ถึง `c14` |
| ดาบ เอซ ถึง ราชา | `s1` ถึง `s14` |
| เหรียญ เอซ ถึง ราชา | `p1` ถึง `p14` |

เลข 1 คือเอซ 2 ถึง 10 คือเลขไพ่ 11 คือเพจ 12 คือไนท์ 13 คือราชินี 14 คือราชา

**วิธีที่ 2 ใช้ชื่อไฟล์เดิมของรูป** เปิดเว็บในเครื่อง กด "เลือกรูปไพ่หลายไฟล์" เลือกรูปทั้งชุด (ชื่อไฟล์ต้องมีชื่อไพ่ เช่น `the-fool.jpg`, `cups03.jpg`, `Pents10.jpg`) แล้วกด "สร้างไฟล์ cards.json" จะได้ไฟล์ที่บอกว่าไพ่ใบไหนใช้ไฟล์ไหน นำ `cards.json` ไปวางในโฟลเดอร์ `cards` พร้อมรูปทั้งหมด

ขนาดรูปที่เหมาะคือสูงไม่เกิน 1,000 พิกเซล ไฟล์ละไม่เกิน 500 KB ช่วยให้เว็บโหลดเร็ว

## ลิขสิทธิ์ของรูปไพ่

เว็บที่ขึ้น GitHub Pages เป็นสาธารณะ ใครก็ดาวน์โหลดรูปในโฟลเดอร์ `cards` ได้ ใช้เฉพาะรูปที่มีสิทธิ์แจกจ่าย เช่น ไพ่ Rider-Waite-Smith ฉบับ ค.ศ. 1909 ที่เป็นสาธารณสมบัติ ส่วนเด็คที่ยังมีลิขสิทธิ์ ไม่ควรอัปโหลดขึ้นเว็บสาธารณะ ให้ผู้ใช้ใส่รูปเองในเครื่อง (ปุ่ม "เลือกรูปไพ่หลายไฟล์") รูปจะเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น

## ผู้ใช้เปลี่ยนรูปเองได้

รูปที่ผู้ใช้ใส่จากปุ่ม "เลือกรูปไพ่หลายไฟล์" หรือ "รูปสำหรับไพ่ใบที่เลือก" จะอยู่ในเบราว์เซอร์ของผู้ใช้คนนั้นและใช้แทนรูปจากโฟลเดอร์ `cards` กด "ลบรูปที่เก็บไว้" เพื่อกลับไปใช้รูปของเว็บ

## ทดสอบในเครื่อง

เปิด `index.html` ด้วยการดับเบิลคลิกได้ แต่ถ้ามีรูปในโฟลเดอร์ `cards` เบราว์เซอร์จะไม่ยอมให้บันทึกเป็น PNG เมื่อเปิดแบบไฟล์ตรงๆ ให้เปิดผ่านเซิร์ฟเวอร์ในเครื่องแทน เช่น ส่วนขยาย Live Server ใน VS Code (กด Go Live) หรือใช้คำสั่ง `python -m http.server` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8000`

## แก้ไขความหมายไพ่

เปิด `meanings.js` ด้วยโปรแกรมแก้ข้อความ แต่ละใบมี 4 ช่อง ตามลำดับ คือ ภาพที่เห็น, คำถามชวนสังเกต, ความหมายตรง, ความหมายกลับหัว แก้ข้อความในเครื่องหมายคำพูดได้เลย

## ชื่อไพ่ภาษาไทย

ชื่อไพ่เมเจอร์อยู่ใน `app.js` ตรงตัวแปร `MAJOR` ช่องที่ 3 ของแต่ละใบคือคำเรียกอื่นที่ใช้ค้นหา ส่วนชื่อลำดับไพ่ชุดย่อยอยู่ใน `RANKS` และชื่อชุดอยู่ใน `SUITS` แก้แล้วช่องค้นหาจะใช้ตามให้เอง (พิมพ์ "3 ถ้วย", "ถ้วย3" หรือ "3 แห่งถ้วย" ก็เจอใบเดียวกัน)

## โต๊ะที่เรียงไว้

เว็บจดโต๊ะที่เรียงไว้ในเบราว์เซอร์ของเครื่องนั้นอัตโนมัติ ปิดแล้วเปิดใหม่ไพ่ยังอยู่ ถ้ากดพลาดใช้ปุ่ม "ย้อนกลับ" หรือ Ctrl+Z (ประวัติย้อนกลับหายเมื่อรีเฟรชหน้า) ข้อควรรู้ Safari บน iPhone อาจล้างข้อมูลเว็บที่ไม่ได้เปิดเกิน 7 วัน ทำให้รูปไพ่ที่ใส่เองจากเครื่องหายได้ ถ้าเป็นเด็คที่แจกจ่ายได้ ให้ใส่ในโฟลเดอร์ `cards` จะปลอดภัยกว่า
